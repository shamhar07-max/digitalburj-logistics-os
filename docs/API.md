# API reference

_Generated by `scripts/gen-api-docs.py` from the route files and CRUD registry — do not edit by hand._

Base URL `/api`. JSON in/out. Authenticated calls send `Authorization: Bearer <access token>`; multi-entity users may send `X-Entity-Id` (omit or `all` for consolidated). Errors: `{ "error": { "message", "code", "details" } }` (400 validation with per-field `details`, 401, 403, 404, 409 conflict/state, 429).

Lists accept `?search=&page=&pageSize=&sort=col:asc|desc&from=&to=` plus the resource's filter columns (comma-separate for multiple values) and return `{ data, total, page, pageSize }`.

## WebSocket

`/ws?token=<access token>` — tenant-scoped domain events (`shipment.status_changed`, `pod.received`, `invoice.paid`, `notification.created`, …). Customer-portal sockets receive only events for their own customer; driver sockets only `trip.*`.
